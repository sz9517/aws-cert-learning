# AWS Certification Learning

> 初學者友善的 **AWS 證照中文學習站**。目標不只是考過，而是**真的學會、用得出來**。

這個網站專為「完全沒碰過 AWS、甚至沒碰過雲端」的人設計。每個主題我們都遵守三個原則：

1. **先講「為什麼需要它」** — 用生活化的例子，讓你知道這個服務在解決什麼真實問題。
2. **專門名詞一定先解釋** — 不預設你懂任何東西；縮寫都會附英文全名與白話說明。
3. **考照 + 實務並重** — 每篇都有「動手做」「真實情境」「常見錯誤」「成本提醒」，考得過也用得出來。

## 這個網站怎麼用？

- 📘 **學習筆記** — 依官方考試領域整理的知識點，白話解釋 + 圖解 + 生活比喻。
- ⚡ **重點速記 / 閃卡** — 點一下翻開說明，考前快速複習。
- ✍️ **原創練習題** — 仿官方考題風格，先自己作答再看詳解。
- 📅 **考試資訊** — 報名、費用、題型、及格分數、讀書計畫。
