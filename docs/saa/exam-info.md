# SAA 考試資訊與讀書計畫

**SAA**（AWS Certified Solutions Architect – Associate，考試代碼 **SAA-C03**）是 AWS 最熱門的入門級架構師證照。

## 考試基本資訊

| 項目 | 內容 |
| --- | --- |
| 考試代碼 | SAA-C03 |
| 題數 | 65 題 |
| 時間 | 130 分鐘 |
| 題型 | 單選題、複選題 |
| 及格分數 | 720 / 1000 |
| 費用 | 150 美元（約新台幣 4,800 元，實際以官方為準） |
| 語言 | 考試可選繁體中文 |
| 形式 | 線上監考或考場應考 |

:::info[最新資訊請以官方為準]
考試費用、題數與政策可能調整，報名前請查閱 [AWS 官方 SAA 認證頁面](https://aws.amazon.com/certification/certified-solutions-architect-associate/)。
:::

## 四大考試領域（權重）

SAA-C03 的考題涵蓋四個領域，**權重就是你該分配讀書時間的比例**：

| 領域 | 中文 | 權重 |
| --- | --- | --- |
| Domain 1 | 設計安全的架構 | **30%** |
| Domain 2 | 設計具彈性（高可用）的架構 | **26%** |
| Domain 3 | 設計高效能的架構 | **24%** |
| Domain 4 | 設計成本最佳化的架構 | **18%** |

## 建議讀書計畫（約 6～8 週）

| 階段 | 內容 | 建議時間 |
| --- | --- | --- |
| 第 1 週 | 入門觀念（為什麼用 AWS、雲端模式、核心服務） | 打基礎 |
| 第 2～3 週 | Domain 1 安全（IAM、加密、網路安全） | 權重最高，先攻 |
| 第 4 週 | Domain 2 彈性（高可用、備援、備份還原） | |
| 第 5 週 | Domain 3 高效能（運算、儲存、資料庫、快取選型） | |
| 第 6 週 | Domain 4 成本最佳化 | |
| 第 7～8 週 | 大量做練習題 + 複習弱點 + 動手做 | 衝刺 |

:::tip[給初學者的建議]
不要只看影片！**每個服務都要自己動手在 AWS 主控台玩過一次**，記憶會深刻非常多。本站每篇都有「動手做」段落帶你操作。記得善用 [AWS 免費方案（Free Tier）](https://aws.amazon.com/free/) 避免產生費用。
:::
