# SAA-C03 綜合模擬考 B 卷（65 題）

這是**第二份**完整模擬卷：題目與第一份完全不同，用來加大練習量、檢驗你是否真的融會貫通。65 題、涵蓋四大領域，題型與配分比照 SAA-C03。每題先自己點選答案，再按「**顯示答案與解析**」對照詳解。所有題目皆為**原創**、仿官方風格（情境式題幹＋限定詞＋含複選），**非真實考題**。

:::info[應考方式建議]
- **題數／時間**：65 題、建議限時 **130 分鐘**（約 2 分鐘/題）。
- **及格線**：官方 **720 / 1000**；本卷可自抓「答對約 47 題（72%）」當通過門檻。
- **領域配分**（比照官方權重）：Domain 1 安全 1–20 題、Domain 2 彈性/高可用 21–37 題、Domain 3 高效能 38–52 題、Domain 4 成本 53–65 題。
- **複選題**會標明「選兩項 / Choose TWO」，務必選滿、不多不少。
- 建議先做完 [第一份模擬考](./mock-exam.md) 再來挑戰這份。
:::

**正解：B**

「長期＋穩定＋大流量＋要降每 GB 單價與穩定低延遲」正是 **Direct Connect（專線）** 的場景：雖然前期建置成本與時間較高，但大流量下每 GB 傳輸單價明顯比走公網的 VPN 便宜，延遲也不受公網影響。A 多架 VPN 仍受公網頻寬與延遲限制、每 GB 單價沒降；C 的 NAT 閘道是私有子網路對外出口、不是機房對接方案；D 的 Internet Gateway 只是 VPC 對外出入口、不提供專線與穩定低延遲。

</Quiz>
