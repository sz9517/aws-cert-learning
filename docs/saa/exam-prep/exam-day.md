# 考試當天須知與線上監考準備

四大領域讀完了、模擬考也刷過了，剩下**最後一關**——而這一關考的不是知識，是「**別在考試當天出包**」。報到遲到、證件帶錯、網路斷線、房間不符規定……這些跟 AWS 架構一點關係都沒有的小事，卻足以讓你白白被取消資格。這一頁就幫你把考前那天該做的準備一次列清楚，讓你安安穩穩把實力發揮出來。

:::tip[這頁的用法]
考前一週把這頁掃一遍、把該做的準備排進行程；考前一天再確認一次清單。選**線上監考**的人尤其要認真看，因為它的規定比到考場嚴格得多。
:::

## 兩種應考方式：考場 vs 線上監考

SAA-C03 可以選兩種方式應考，報名時就要決定。沒有絕對好壞，看你的環境與偏好：

| 比較項目 | 考場應考（Test Center，Pearson VUE） | 線上監考（OnVUE，online proctored） |
| --- | --- | --- |
| 地點 | 到指定的 Pearson VUE 考場 | 在家或任何符合規定的私人空間 |
| 設備 | 考場提供電腦與環境 | 用自己的電腦，需先通過系統測試 |
| 監考方式 | 現場考官監督 | 透過鏡頭與麥克風由線上監考人員遠端監督 |
| 彈性 | 需配合考場地點與時段、要通勤 | 不用出門、時段選擇多 |
| 環境干擾 | 環境穩定、不必自己張羅 | 需自備安靜淨空的獨立空間，網路要穩 |
| 規定嚴格度 | 相對單純，到場報到即可 | 較嚴格：房間、桌面、鏡頭、進出都有規範 |
| 適合誰 | 怕家裡網路或環境不達標、想要省心 | 住得離考場遠、想在熟悉環境作答 |

:::info[實際以官方為準]
兩種方式是否都開放、各地考場是否可預約、線上監考的支援語言與時段，依地區而不同。報名與方式選擇請以 [AWS 認證報名頁](https://www.aws.training/certification) 與 [Pearson VUE](https://home.pearsonvue.com/aws) 的最新公告為準。
:::

## 線上監考（OnVUE）準備重點

線上監考最常出狀況，一旦不符規定可能無法開考甚至被取消，請務必逐項確認：

- **事前先跑系統測試**：報名後，用「你考試當天要用的那台電腦、那個網路」執行 Pearson VUE 提供的 OnVUE 系統測試，確認攝影機、麥克風、網路都通過。別等到考試當天才第一次測。
- **穩定的網路**：優先用穩定的有線或強訊號 Wi-Fi，考試期間請其他人暫停下載／串流，避免斷線中斷考試。
- **可拍照的本人身分證件**：準備好符合規定、含照片與姓名的有效<Term en="government-issued ID" desc="政府核發的身分證件，例如護照、身分證或駕照">身分證件</Term>，報到時要用鏡頭拍清楚。姓名需與報名一致。
- **安靜且淨空的獨立空間**：單獨一個房間、關門、沒有其他人進出。**桌面要淨空**——不能有紙、筆、書本、便條、手機、耳機，也**不能有第二個螢幕**（多螢幕要拔掉或關閉）。
- **全程不能離開鏡頭**：考試中不可起身、不可離開畫面、不可讀題出聲、不可與他人交談。中途離開可能被判違規。
- **報到時要拍環境與證件**：報到流程會請你用鏡頭拍攝證件，並環拍一圈房間（含桌面上下、牆面）證明空間淨空，之後才由監考人員放行開考。
- **提早 30 分鐘報到**：報到與檢查要花時間，請預留、提早約 **30 分鐘**開始報到流程，免得匆忙出錯。

:::warning[線上監考最容易踩的雷]
桌上忘了收手機、房裡有家人走動、戴著耳機、開著雙螢幕——這些都可能讓監考人員直接喊停。考前把桌面與房間徹底清空，手機收到看不到的地方。
:::

:::info[實際以官方為準]
OnVUE 的系統需求、可／不可攜帶物品、休息規定與報到流程會不定期更新，請在考前以 [Pearson VUE OnVUE 說明](https://home.pearsonvue.com/aws/onvue) 的最新版本為準。
:::

## 考場應考準備

選到考場考就輕鬆得多，但也別大意：

- **帶齊兩種有效證件**：通常需要兩份有效證件，且**至少一份含照片**，姓名都要與報名一致。出門前再確認一次。
- **提早到場報到**：預留交通與報到時間，建議提早約 **30 分鐘**抵達，先熟悉環境、上個廁所、穩定心情。
- **使用置物櫃**：個人物品（手機、包包、書本、手錶、外套等）通常需放進考場提供的<Term en="locker" desc="考場提供的上鎖置物櫃，存放不能帶進考場的個人物品">置物櫃</Term>，不能帶進考試區。

:::info[實際以官方為準]
各考場可攜帶物品、置物規定與可接受的證件種類略有不同，請以 Pearson VUE 考場的實際規定與預約通知為準。
:::

## 考試當天時間與作答策略

真正開考後，策略跟你在[考前衝刺頁](./cram.md)練過的一致，這裡再提醒幾個當天最實用的：

- **65 題、130 分鐘**：平均約 **2 分鐘／題**，別在單一難題上卡太久。
- **善用標記（flag）**：不確定的題目先**標記稍後回看**，把會的分數先穩穩拿下，剩時間再回頭攻難題。
- **先穩拿會的**：及格靠整體過線，不必題題全對，先把有把握的拿滿最重要。
- **複選題看清 Choose TWO**：題目寫明「**Choose TWO**」就要**剛好選兩個**，少選或多選都算錯。
- **介面語言可切換**：作答中可切換繁體中文／英文介面，看不懂中文翻譯時可切回英文原文對照。SAA 可選**繁體中文**。

:::tip[作答節奏]
第一輪先把會的全部做完並標記不確定的；第二輪專攻標記題；最後留幾分鐘檢查複選題有沒有選滿、有沒有看錯限定詞。
:::

## 成績與證照

- **考完先看到初步結果**：交卷後通常會先看到**初步的 pass / fail（及格／不及格）**結果。
- **正式成績稍後送達**：完整成績報告與數位**徽章**（electronic badge）會在之後透過電子郵件／AWS 認證帳戶寄達，不是當下立刻拿到。
- **及格線 720 / 1000**：滿分 1000，**720 分**即及格；分數是量尺計分，重點是整體過線。

:::info[實際以官方為準]
成績公布時間、成績報告格式與徽章發放流程可能調整，請以 AWS 認證帳戶與官方通知為準。
:::

## 心態提醒

:::tip[考前最後一晚]
- **睡飽最重要**：充足睡眠對答題表現的幫助，遠大於熬夜多看那幾頁。
- **別臨時抱佛腳到深夜**：考前一晚最多輕鬆掃一遍衝刺重點就好，不要再硬塞新內容，弄到精神不濟反而失分。
- **相信你的準備**：你已經走完四大領域與模擬考，深呼吸，穩穩把實力發揮出來就好。
:::
