# CLF 考試資訊與讀書地圖

**CLF**（AWS Certified Cloud Practitioner，考試代碼 **CLF-C02**）是 AWS 最入門的基礎級證照。它不要求你會寫程式，也不會叫你設計複雜的系統架構，而是確認你**聽得懂雲端在講什麼、知道 AWS 大概有哪些服務、懂基本的安全與帳務觀念**。

<Analogy title="💡 比喻：CLF 像是「汽車的交通規則與常識」，SAA 才是「學開車上路」">

想像你要學開車。

**CLF** 等於先把交通規則、路標、油電差別、保養常識搞懂——你不用馬上會停車入庫，但你知道整台車大概怎麼運作、油門煞車各管什麼。

**SAA** 才是真的坐進駕駛座，練習各種路況下該怎麼操作。

先把常識建立好，再上路學細節，整個過程會順很多；而且就算你不是駕駛（例如你是乘客、是車隊調度），懂這些常識也能跟大家溝通。

</Analogy>

## 為什麼建議把 CLF 當第一張證照

- **偏廣度與觀念，不偏深**：CLF 要你「知道有這個東西、大概是做什麼的」，不會逼你記一堆設定細節或參數。
- **不考複雜架構**：沒有實作題，也不會要你設計高可用、多區域的系統——那是 SAA 以後的事。
- **適合完全新手**：第一次接觸雲端的人，可以用它建立整體地圖，不會一開始就被細節淹沒。
- **適合非工程職**：專案經理（PM）、業務、主管等，考 CLF 能和工程團隊建立**共同語言**，開會討論時聽得懂、問得出重點。
- **讓後面更順**：很多雲端概念（責任共擔、全球基礎建設、定價模式）在 CLF 先打過底，之後進 SAA 會覺得「這我看過」，學起來省力很多。

:::tip[給完全新手的話]
就算你不打算當工程師，CLF 也很值得考。它給你的是一整套**雲端的共同語言**，讓你在任何跟雲有關的場合都不再一頭霧水。
:::

## 考試基本資訊

| 項目 | 內容 |
| --- | --- |
| 考試代碼 | CLF-C02 |
| 題數 | 65 題 |
| 時間 | 90 分鐘 |
| 題型 | 單選題、複選題 |
| 及格分數 | 700 / 1000 |
| 費用 | 約 100 美元（實際以官方為準） |
| 語言 | 考試可選繁體中文 |
| 形式 | 線上監考或考場應考 |
| 實作題 | 無（全部是選擇題） |

:::info[最新資訊請以官方為準]
考試費用、題數與政策可能調整，報名前請查閱 [AWS 官方 CLF 認證頁面](https://aws.amazon.com/certification/certified-cloud-practitioner/)。
:::

## 四大考試領域（權重）

CLF-C02 的考題涵蓋四個領域，**權重就是你該分配讀書時間的比例**：

| 領域 | 中文 | 權重 |
| --- | --- | --- |
| Cloud Concepts | 雲端概念 | **24%** |
| Security and Compliance | 安全與合規 | **30%** |
| Cloud Technology and Services | 雲端技術與服務 | **34%** |
| Billing, Pricing and Support | 帳務、定價與支援 | **12%** |

<Term en="Compliance" desc="合規，指符合法規、產業標準與內部政策的要求，例如資料保護、稽核等。" />

從權重看得出來：**安全與合規（30%）** 和 **雲端技術與服務（34%）** 合計超過六成，是最該花時間的兩塊；雲端概念雖然只有 24%，卻是其他領域的基礎，建議最先讀。

## 讀書地圖：站上內容怎麼對應 CLF

你不需要另外找教材，本站既有的內容就足以涵蓋 CLF 的範圍。建議的讀法分成三步。

**第一步，入門必讀。** 先把「入門」區讀過一輪，這一區專門建立雲端的整體觀念，正好對應 CLF 最重視的基礎：雲端到底是什麼、AWS 的全球基礎建設（區域、可用區）、責任共擔模型（哪些安全由 AWS 負責、哪些由你負責）、Well-Architected 的設計精神，以及一張 AWS 服務地圖讓你知道常見服務各自在做什麼。讀完這一區，你對雲端的整體樣貌就有了基本的輪廓。

**第二步，攻本區四篇。** CLF 區接下來的四篇文章，會分別對應 CLF 的四大領域——雲端概念、安全與合規、雲端技術與服務、帳務定價與支援——把每個領域的考試重點濃縮整理，幫你把入門學到的觀念對準考題。

**第三步，做練習題。** 最後用 CLF 練習題檢驗自己，模擬實際的情境式單選與複選題，找出還不熟的地方回頭補強。做題時不要只看對錯，要看懂每一題背後考的是哪個觀念。

:::note[一句話總結]
入門區打底 → CLF 四篇對準考點 → 練習題收尾。照這個順序走，你會發現 CLF 其實是一條很平緩的上手路。
:::
