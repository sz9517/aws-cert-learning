# 雲端到底是什麼？

「雲端（Cloud）」聽起來很玄，其實意思很單純：

> **把原本要放在自己公司的電腦（伺服器），改成用網路租用別人（例如 AWS）蓋好的電腦。**

你透過網路使用這些電腦的運算、儲存、資料庫等能力，<Term desc="用多少付多少，像水電費一樣按用量計費，不用一次買斷。">按用量付費</Term>，不需要自己買硬體。

<Analogy title="🏠 比喻：買房 vs. 租房">

- **自建機房** = 買房：一次砸大錢、要自己修繕、搬家麻煩。
- **用雲端** = 租房：月租、壞了房東修、想換大一點馬上換。

</Analogy>

## 雲端的三種服務模式（考試會考）

| 模式 | 全名 | 白話 | 生活比喻 |
| --- | --- | --- | --- |
| **IaaS** | Infrastructure as a Service | 租「基礎設施」，自己裝軟體 | 租一間空房，家具自己買 |
| **PaaS** | Platform as a Service | 租「平台」，你只管寫程式 | 租附家具的套房，拎包入住 |
| **SaaS** | Software as a Service | 直接用「現成軟體」 | 住飯店，什麼都有人打理 |

:::note[這跟 SAA 有什麼關係？]
SAA 大多在玩 **IaaS / PaaS** 等級的服務（像 <Term en="Elastic Compute Cloud" desc="AWS 上租來的一台雲端伺服器。">EC2</Term>、<Term en="Simple Storage Service" desc="AWS 的雲端檔案倉庫。">S3</Term>）。知道這三種模式的差別，遇到相關題目就不會慌。
:::
