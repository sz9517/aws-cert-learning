# AWS Certification Roadmap

AWS certifications come in several levels, from entry to expert. This map shows **every certification available**, **what each one tests**, and the **recommended order** to tackle them. The ones marked <span className="roadmap-badge roadmap-badge--inline">★ Covered here</span> link straight into this site's full course.

This map is a simplified version put together by this site. For AWS's full official certification overview (with details on every exam and the latest changes), see 👉 the [official AWS Certification page](https://aws.amazon.com/certification/), and for each exam's official guide, the [AWS Certification Exam Guides](https://docs.aws.amazon.com/aws-certification/latest/examguides/aws-certification-exam-guides.html).
:::

## 🧭 Suggested path for beginners

1. **Brand new to the cloud** → start with <Link to="/clf">Cloud Practitioner (CLF-C02)</Link> to build the big picture and vocabulary fast.
2. **Aiming for an architect / IT role** → focus on <Link to="/saa/exam-info">Solutions Architect – Associate (SAA-C03)</Link>, the most popular and widely recognized cert.
3. **Going further** → pick a Professional or Specialty based on your career path; for an AI focus, follow the AI Practitioner → GenAI Developer track.

:::tip[Covered on this site]
Full English courses, labs, and original practice questions for **CLF-C02** and **SAA-C03**. The rest are on the map so you can see the whole journey.
:::

:::warning[Exam codes change]
AWS revises exams periodically (e.g. C02 → C03). This page reflects the 2026 versions; always confirm on the [official AWS Certification page](https://aws.amazon.com/certification/) before registering.
