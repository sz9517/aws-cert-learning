# CLF Exam Info & Study Map

**CLF** (AWS Certified Cloud Practitioner, exam code **CLF-C02**) is AWS's most entry-level foundational certification. It doesn't require you to write code, and it won't ask you to design a complex system architecture. Instead, it confirms that you **understand what the cloud is about, know roughly what services AWS offers, and grasp the basics of security and billing**.

<Analogy title="💡 Analogy: CLF is like the rules of the road, while SAA is learning to actually drive">

Imagine you want to learn to drive.

**CLF** is like first getting the traffic rules, road signs, the difference between gas and electric, and basic maintenance knowledge straight. You don't need to parallel-park right away, but you understand how the whole car works and what the gas and brake pedals each do.

**SAA** is when you actually sit in the driver's seat and practice handling all kinds of road conditions.

Build the common knowledge first, then get on the road to learn the details — the whole process goes much more smoothly. And even if you're not the driver (say you're a passenger or a fleet dispatcher), knowing these basics lets you communicate with everyone else.

</Analogy>

## Why we recommend CLF as your first certification

- **Breadth and concepts, not depth**: CLF wants you to "know this thing exists and roughly what it does" — it won't force you to memorize piles of configuration details or parameters.
- **No complex architecture**: There are no hands-on labs, and it won't ask you to design highly available, multi-region systems — that comes later with SAA.
- **Great for complete beginners**: If this is your first contact with the cloud, CLF helps you build the overall map without being drowned in details from day one.
- **Great for non-engineering roles**: Project managers (PMs), sales, and team leads can take CLF to build a **shared language** with engineering teams, so they can follow discussions and ask the right questions in meetings.
- **Makes later study smoother**: Many cloud concepts (shared responsibility, global infrastructure, pricing models) get a first pass in CLF, so when you move on to SAA you'll think "I've seen this before" and learn it with much less effort.

:::tip[A word for complete beginners]
Even if you don't plan to become an engineer, CLF is well worth taking. What it gives you is a complete **shared language of the cloud**, so you're never lost in any cloud-related setting again.
:::

## Exam basics

| Item | Details |
| --- | --- |
| Exam code | CLF-C02 |
| Questions | 65 |
| Time | 90 minutes |
| Question types | Single-choice and multiple-response |
| Passing score | 700 / 1000 |
| Fee | About USD 100 (confirm with official sources) |
| Language | Traditional Chinese is available |
| Format | Online proctored or at a test center |
| Hands-on labs | None (all multiple-choice) |

:::info[Confirm the latest info with official sources]
Exam fees, question counts, and policies may change. Before registering, check the [official AWS CLF certification page](https://aws.amazon.com/certification/certified-cloud-practitioner/).
:::

## The four exam domains (weighting)

CLF-C02 questions span four domains, and **the weighting is exactly how you should split your study time**:

| Domain | Name | Weight |
| --- | --- | --- |
| Cloud Concepts | Cloud Concepts | **24%** |
| Security and Compliance | Security and Compliance | **30%** |
| Cloud Technology and Services | Cloud Technology and Services | **34%** |
| Billing, Pricing and Support | Billing, Pricing and Support | **12%** |

<Term en="Compliance" desc="Meeting the requirements of laws, industry standards, and internal policies, such as data protection and auditing." />

The weighting makes it clear: **Security and Compliance (30%)** plus **Cloud Technology and Services (34%)** together make up over 60%, so those are the two areas to spend the most time on. Cloud Concepts is only 24%, but it's the foundation for everything else, so read it first.

## Study map: how the site's content maps to CLF

You don't need to go find separate materials — the content already on this site covers the CLF scope. Here's the recommended three-step approach.

**Step one: the Getting Started essentials.** Work through the "Getting Started" section once. This section is dedicated to building the overall picture of the cloud, which maps perfectly to what CLF values most at the foundational level: what the cloud actually is, AWS's global infrastructure (Regions and Availability Zones), the shared responsibility model (which security AWS handles and which is on you), the design spirit of the Well-Architected Framework, and a map of AWS services so you know what the common ones each do. After this section, you'll have a basic outline of what the cloud looks like as a whole.

**Step two: the four articles in this section.** The next four articles in the CLF section each map to one of CLF's four domains — Cloud Concepts, Security and Compliance, Cloud Technology and Services, and Billing, Pricing and Support. They distill the key exam points of each domain to help you aim the concepts from Getting Started squarely at the exam questions.

**Step three: practice questions.** Finally, test yourself with the CLF practice questions, which simulate the real scenario-based single-choice and multiple-response format, so you can find weak spots and go back to shore them up. When you practice, don't just check right or wrong — understand which concept each question is really testing.

:::note[In one sentence]
Getting Started builds the base, the four CLF articles aim at the exam points, and practice questions wrap it up. Follow this order and you'll find CLF is actually a very gentle on-ramp.
:::
