# SAA Exam Info & Study Plan

**SAA** (AWS Certified Solutions Architect – Associate, exam code **SAA-C03**) is AWS's most popular entry-level architect certification.

## Exam basics

| Item | Details |
| --- | --- |
| Exam code | SAA-C03 |
| Questions | 65 |
| Time | 130 minutes |
| Format | Multiple choice, multiple response |
| Passing score | 720 / 1000 |
| Fee | USD 150 (actual price per official site) |
| Languages | Multiple languages available, including English |
| Delivery | Online proctored or at a test center |

:::info[Always check the official site]
Exam fees, question counts, and policies may change. Before registering, check the [official AWS SAA certification page](https://aws.amazon.com/certification/certified-solutions-architect-associate/).
:::

## The four exam domains (weighting)

SAA-C03 questions span four domains. **The weighting is how you should split your study time:**

| Domain | Name | Weight |
| --- | --- | --- |
| Domain 1 | Design Secure Architectures | **30%** |
| Domain 2 | Design Resilient (highly available) Architectures | **26%** |
| Domain 3 | Design High-Performing Architectures | **24%** |
| Domain 4 | Design Cost-Optimized Architectures | **18%** |

## Suggested study plan (about 6–8 weeks)

| Phase | Content | Suggested time |
| --- | --- | --- |
| Week 1 | Intro concepts (why AWS, cloud models, core services) | Build the foundation |
| Weeks 2–3 | Domain 1 Security (IAM, encryption, network security) | Highest weight — tackle first |
| Week 4 | Domain 2 Resilience (high availability, redundancy, backup/restore) | |
| Week 5 | Domain 3 Performance (compute, storage, database, caching choices) | |
| Week 6 | Domain 4 Cost optimization | |
| Weeks 7–8 | Lots of practice questions + review weak spots + hands-on | Final sprint |

:::tip[Advice for beginners]
Don't just watch videos! **Try every service hands-on in the AWS console at least once** — it makes the memory far stronger. Every page on this site has a "hands-on" section to walk you through it. Remember to use the [AWS Free Tier](https://aws.amazon.com/free/) to avoid charges.
:::
